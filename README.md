# Try_sending_it_back_for_revision_challenge_7

# Лабораторная работа: Определение в тексте частоты повторения букв и двубуквенных сочетаний

## Автор
Захаров Никита (В задании вариант не учитывается)

## Цель
Практическое освоение C++ и закрепление навыков программирования с помощью задачи.

## Описание
Программа принимает текст из одного файла, определяет в нем частоту повторения букв и двубуквенных сочетаний и выводит результаты на консоль и в другой файл.

## Исходные данные
- Файл "text.txt" с текстом;
- Файл "result.txt", куда программа выведет результаты.

## Ожидаемые результаты
Программа выведет частоту повторения букв и двубуквенных сочетаний на консоль и в файл "result.txt".
